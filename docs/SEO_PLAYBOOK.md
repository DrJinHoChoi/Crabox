# 스마트이어 주식회사 · 데이터피디 — 검색 브랜딩 플레이북

> 현황(2026-10 조사): "스마트이어 주식회사", "데이터피디"를 **각각 따로** 검색해도 직접 다룬 결과가 **거의 없음**
> (비슷한 이름의 타사만 노출: 스마트데이터 주식회사, 주식회사 이스마트 등).
> → 부정 콘텐츠를 걱정하기 전에 **공식 콘텐츠로 검색 결과 1페이지를 채우는 것**이 가장 빠르고 확실한 전략입니다.
> 검색 결과는 한 페이지에 10개 안팎이라, 공식·신뢰 채널 10곳이 상위를 차지하면 브랜드 검색어 결과는 자연스럽게 우리 콘텐츠 위주가 됩니다.

## 0단계: 두 이름을 따로 운영

| | 스마트이어 주식회사 | 데이터피디 |
|---|---|---|
| 정체성 | 법인 (주식회사) | **개인사업자** (별개 사업자) |
| 설정 | `config/smartear.toml` | `config/datapd.toml` |
| 사업자등록번호 | 법인 번호 | 데이터피디 자체 번호 |
| 사이트 | 스마트이어 도메인 (`site/smartear/`) | 데이터피디 도메인 (`site/datapd/`) |
| schema.org | `Organization` + legalName (단독) | `Organization` + legalName (단독) |
| 핵심 채널 | 기업정보 플랫폼, 채용 페이지, 보도자료, 링크드인 | 네이버 블로그, 유튜브, 인스타그램, 고객 사례 |
| 검색 의도 | 투자자·구직자·거래처 "어떤 회사?" | 잠재 고객 "어떤 서비스? 후기?" |
| 주요 부정 키워드 | 체불·갑질·소송·폐업 | 환불·먹튀·효과 없음 |

- **검색엔진에 알리는 정체성은 완전히 독립**입니다. 두 사이트·채널은 서로 링크하지 않고, 상대 이름·도메인·관계 정보(schema.org `brand`/`parentOrganization` 등)도 넣지 않습니다. 각 검색어마다 해당 공식 페이지만 1순위로 잡히게 하기 위함입니다. (`tests/test_basic.py`의 `test_identities_are_independent`가 이를 검증)
- 공식 채널(블로그·SNS 계정)도 엔티티별로 **별도 계정**을 운영하고, 각 toml의 `same_as`에는 자기 채널만 넣습니다.
- 네이버 서치어드바이저·구글 서치콘솔도 **사이트별로 따로** 등록합니다.
- 두 사업자는 **법적으로 별개**이므로 하단 사업자 정보(상호·대표·사업자등록번호)도 각자 자기 것만 표시합니다. 전자상거래법상 표시 의무를 지켜도 서로 연결되지 않습니다.
- 기업정보 플랫폼·네이버 스마트플레이스·잡플래닛도 **사업자등록번호별로 따로** 등록·관리합니다.
- 데이터피디는 "데이터 PD"(일반 직무명)와 혼동되기 쉬우므로 항상 **붙여서 "데이터피디"**, 영문 **"DataPD"**로 통일합니다.

## 1단계 (1~2주): 검색엔진에 "공식 회사" 등록

| 할 일 | 효과 | 비고 |
|---|---|---|
| 도메인 2개 + `python -m seo.generate_site` 결과(`site/smartear`, `site/datapd`) 각각 배포 | 각 이름 검색 시 1순위 후보 | JSON-LD로 사업자 정보 구조화 |
| **네이버 서치어드바이저** 사이트 등록, 사이트맵 제출 | 네이버 웹문서 노출 | 인증 값은 각 toml의 `naver_site_verification` |
| **구글 서치콘솔** 등록, 사이트맵 제출 | 구글 노출 + 지식 패널 후보 | `google_site_verification` |
| **네이버 스마트플레이스**(사업장 등록) | 지도·플레이스 영역 노출 | 사업자등록증 필요 |
| **네이버 검색 '공식 홈페이지' 표시** 신청 | 회사명 검색 최상단 공식 링크 | 서치어드바이저/고객센터 |
| 다음(카카오) 검색 등록 | 다음 노출 | register.search.daum.net |

## 2단계 (1~3개월): 상위 노출 채널 채우기

채널마다 **해당 이름 하나만 정확히 반복**하세요: 스마트이어 채널은 "스마트이어 주식회사", 데이터피디 채널은 "데이터피디(DataPD)". 표기가 매번 다르면 검색엔진이 하나의 엔티티로 묶지 못합니다.

1. **네이버 블로그 (공식)** — 네이버 브랜드 검색에서 가장 강력. 주 1~2회, 사례·인사이트·회사 소식.
2. **보도자료** — 투자·협약·수상·신규 서비스 등 *실제 소식*이 있을 때 배포 (뉴스 영역 상위 노출).
3. **유튜브 / 인스타그램 / 링크드인 공식 계정** — 프로필에 동일한 회사명·홈페이지 링크.
4. **기업 정보 플랫폼** — 더브이씨(thevc.kr), 혁신의숲, 넥스트유니콘, 잡코리아/사람인 기업정보, 원티드 회사 페이지 프로필 정확히 작성.
5. **브런치 / 티스토리** — 대표·임직원의 전문성 콘텐츠 (구글 노출에 유리).
6. 모든 공식 채널 URL을 해당 toml(`smartear.toml` / `datapd.toml`)의 `same_as`에 추가 → 사이트 재생성.

## 3단계 (상시): 모니터링 & 부정 콘텐츠 대응

`python -m monitor.brand_monitor` 를 주 1회 실행(또는 cron/GitHub Actions)하면 `reports/smartear/`, `reports/datapd/`에 따로 정리되고, 부정 신호 게시물이 리포트 상단에 나옵니다.

### 부정 콘텐츠 대응 원칙 — 합법적이고 효과적인 방법만

| 상황 | 대응 |
|---|---|
| **잡플래닛 과거 리뷰** | `docs/JOBPLANET_PLAYBOOK.md` 참고 — 삭제가 아니라 최근 리뷰·사실 기반 답변·현재 모습으로 덮기 |
| **사실인 불만·후기** (서비스 불만, 환불 지연 등) | 해당 게시물/플랫폼에 **공식 답변**, 문제 해결 후 해결 사실 안내. 원만히 해결되면 작성자가 자발적으로 수정·삭제하기도 함. 잡플래닛 등은 기업 공식 답변 기능 사용. |
| **명백한 허위사실·명예훼손·모욕** | 네이버/카카오/구글 등 플랫폼에 **권리침해 신고(게시중단 요청, 임시조치)** — 정보통신망법 제44조의2. 증빙(사실과 다른 근거) 첨부. 구글은 "법적 사유로 콘텐츠 삭제 요청" 양식. |
| **개인정보 노출** (임직원 실명·연락처 등) | 플랫폼 개인정보 침해 신고, 구글 개인정보 삭제 요청. |
| **오래되어 사라진 페이지가 검색에 남음** | 구글 "오래된 콘텐츠 삭제" 도구, 네이버 "검색 결과 삭제 요청(삭제된 게시물)". |
| **사안이 크거나 반복적** | 법무법인 상담 후 내용증명 / 법적 조치. |

### 하지 않을 것 (역효과 + 법적 위험)

- ❌ 가짜 후기·댓글, 직원/지인 계정으로 리뷰 작성, 리뷰 대행 업체 이용 → **표시광고법 위반(기만 광고)**, 공정위 제재 대상, 발각 시 브랜드 신뢰 붕괴.
- ❌ 키워드 도배용 대량 블로그·스팸 페이지 (저품질 판정 → 공식 채널까지 노출 하락).
- ❌ 사실인 비판 글을 허위 신고로 내리기 (업무방해·무고 소지, 2차 논란).
- ❌ 위키(나무위키 등) 문서를 회사가 직접 홍보성으로 편집 (이해충돌, 되돌림·논란 위험).

광고 표시가 붙은 정식 협찬 콘텐츠(체험단·인플루언서)는 **"광고/협찬" 명시**만 지키면 괜찮습니다.
