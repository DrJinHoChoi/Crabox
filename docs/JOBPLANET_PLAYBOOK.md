# 잡플래닛 — 5년 전 이미지 탈피 플레이북 (스마트이어 주식회사)

## 핵심 원리

잡플래닛 리뷰는 **법인(사업자등록번호)에 귀속**되어 회사가 직접 지울 수 없고, 잡플래닛은 금전 거래를 포함해 어떤 사유로도 리뷰를 삭제·조작하지 않는다는 입장입니다.
따라서 과거 리뷰를 없애는 게 아니라 **"그건 예전 얘기이고 지금은 다르다"는 증거를 쌓는 것**이 유일하게 통하는 방법입니다.

방문자(구직자)는 대개 ① 최근 리뷰, ② 별점 추이, ③ 기업의 답변 태도를 봅니다. 이 세 가지를 바꾸면 5년 전 리뷰는 "예전에 그랬던 회사"로 읽힙니다.

```
과거 리뷰 (못 지움)  →  ① 최근 솔직한 리뷰가 쌓임   →  "요즘은 달라졌네"
                        ② 과거 리뷰에 사실 기반 답변  →  "회사가 인정하고 고쳤네"
                        ③ 외부 채널에 현재 모습       →  "실제로 이런 회사구나"
```

## 1단계: 진단 (1주)

1. 잡플래닛 기업회원 가입 → 회사 페이지 관리 권한 확보
2. 리뷰를 `data/jobplanet_reviews.csv`로 옮겨 적기 (형식: `data/jobplanet_reviews.sample.csv`). 잡플래닛은 자동 수집을 허용하지 않으므로 직접 옮깁니다.
3. 분석 실행
   ```bash
   python -m jobplanet.review_analyzer data/jobplanet_reviews.csv
   ```
4. 리포트에서 주제를 세 가지로 나눔
   - **개선 → 홍보 소재**: 과거엔 많았지만 최근엔 줄어든 불만 → 알리면 되는 것
   - **여전함 → 실제 개선 필요**: 지금도 나오는 불만 → 홍보로는 해결 안 됨, 제도부터 바꿔야 함
   - **신규 이슈**: 최근 새로 생긴 불만 → 원인 점검

> ⚠️ "여전함" 주제를 그대로 두고 홍보만 하면 새 리뷰가 같은 내용을 반복해서 이미지가 굳습니다. 이미지가 안 바뀌는 가장 흔한 원인입니다.

## 2단계: 과거 리뷰에 답변 (2~3주)

잡플래닛은 기업 담당자가 리뷰에 **댓글(공식 답변)**을 달 수 있게 하고, 오해를 풀고 조언에 답하는 댓글을 권장합니다.
분석기가 **답변이 없는 별점 3점 이하 리뷰**마다 주제에 맞는 답변 초안을 만들어 줍니다.

답변 원칙:
- **인정 → 바뀐 사실 → 감사** 순서. 변명이나 반박은 하지 않습니다.
- `{개선사항}`에는 **제도명, 시행 시기, 수치**를 넣습니다. 예: "2024년부터 연 2회 연봉 협상, 평균 인상률 6%", "2025년 3월 전사 재택 주 2회 도입".
- **사실이 아닌 개선은 쓰지 않습니다.** 현직자가 반박 리뷰를 쓰면 역효과가 큽니다.
- 5년 전 리뷰라면 "당시 경영 체계가 미흡했던 점을 인정합니다"처럼 **시점을 분명히** 해 "과거의 일"로 정리합니다.

예시:
> 2021년 당시 업무 체계가 부족해 야근이 잦았던 점, 솔직하게 말씀해 주셔서 감사합니다. 이후 2023년 업무 분장 제도와 PC-OFF 제도를 도입했고, 현재 월평균 초과근무는 N시간 수준입니다. 남겨주신 의견이 회사가 바뀌는 계기가 되었습니다.

## 3단계: 최근 리뷰 늘리기 (상시)

과거 리뷰 비중을 줄이는 유일한 방법은 **최근 리뷰가 늘어나는 것**입니다.

| ✅ 해도 됨 | ❌ 하면 안 됨 |
|---|---|
| 전사 공지로 "잡플래닛에 솔직한 리뷰를 남겨 달라"고 안내 (긍정·부정 무관) | 긍정 리뷰 작성 강요, 별점 지정 |
| 퇴사 면담 때 리뷰 작성 안내 | 긍정 리뷰 조건으로 보상·인센티브 지급 |
| 리뷰 작성 여부를 묻지 않음 (익명성 존중) | 작성자 색출, 작성 여부 확인 |
| | 회사·대행사가 직원인 척 리뷰 작성 |

❌ 항목은 잡플래닛 운영정책 위반으로 리뷰 블라인드나 기업 페이지 제재를 받을 수 있습니다. 강요는 **직장 내 괴롭힘**(근로기준법 제76조의2)이 될 수 있고, 조작된 리뷰는 표시광고법상 기만 광고 소지가 있습니다. 운영팀도 작성자를 알 수 없고, 작성자가 드러날 만한 리뷰는 거절되므로 색출은 불가능하고 시도만으로 논란이 됩니다.

## 4단계: 기업 페이지 & 외부 채널에서 현재 모습 보여주기

1. **잡플래닛 기업 정보 최신화**: 회사 소개, 복리후생, 채용 공고를 현재 기준으로 작성합니다. 2단계의 "개선" 항목을 구체적으로 적습니다.
2. **잡플래닛 기업 브랜딩 상품**(유료, 기업회원 안내 참고): 회사 소개 콘텐츠, 인터뷰 등을 페이지 상단에 노출합니다.
3. **채용 브랜딩 콘텐츠**: 공식 블로그·링크드인·채용 페이지에 "일하는 방식", 구성원 인터뷰, 제도 변화 타임라인을 올립니다.
   → "스마트이어 주식회사" 검색 결과에서 잡플래닛보다 위에 노출되는 공식 콘텐츠가 늘어납니다 (`SEO_PLAYBOOK.md` 2단계).
4. **제3자 인증**: 일자리 관련 인증(청년친화강소기업, 가족친화인증, 일하기 좋은 기업 선정 등)을 받으면 보도자료와 채용 페이지에 활용합니다. 공신력 있는 "현재" 증거입니다.

## 5단계: 블라인드 요청 (해당될 때만)

잡플래닛 블라인드는 **권리침해가 인정된 콘텐츠**에만 적용됩니다. 오래되었거나 부정적이라는 이유만으로는 안 됩니다.

| 블라인드 요청 가능성 있음 | 불가 |
|---|---|
| 특정 개인을 식별할 수 있는 정보(실명, 직책 특정) | 오래된 리뷰 |
| 증빙으로 반박 가능한 명백한 허위사실 | 부정적인 평가·의견 |
| 욕설, 모욕, 성적 표현 | 회사가 동의하지 않는 주관적 평가 |

요청 절차와 필요한 증빙은 잡플래닛 고객센터·운영정책 페이지에서 최신 내용을 확인하세요.

## 성과 지표 (분기마다 분석기를 다시 실행)

- [ ] 최근 2년 리뷰 수가 과거 리뷰 수를 넘었는가
- [ ] 최근 평균 별점이 과거보다 0.5점 이상 높은가
- [ ] 별점 3점 이하 리뷰 답변률 100%
- [ ] "여전함" 주제 수 감소
- [ ] "스마트이어 주식회사" 네이버/구글 1페이지 중 공식 콘텐츠가 5개 이상인가
